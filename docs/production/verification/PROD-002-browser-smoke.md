# PROD-002 — browser smoke test

**Дата:** 14 августа 2026 г.  
**Среда:** локальная Vite development build, Chromium sandbox.

## Подтверждено

После запуска отображается selector **«Уровень · 3 задания»** с тремя authored levels из versioned manifest. Текущий level отображается как `Гостиная: Первые шаги`; локальный профиль восстанавливается. Каталог статически доступен в собранной web-версии.

## Подтверждённый interaction path

Первый автоматизированный click не дал немедленно наблюдаемого изменения в извлечённой странице, поэтому этот путь был перепроверен через DOM с коротким ожиданием асинхронной загрузки. Проверка подтвердила, что выбор `Уютный уголок` меняет заголовок активной комнаты с `Гостиная: Первые шаги` на `Уютный уголок`, переносит `aria-current="true"` на `level-002` и сохраняет `lastSession.levelId: "level-002"` в `decorium.player-profile`. Ошибок в консоли не обнаружено.

## Resume after reload

После полной перезагрузки страницы игра автоматически открыла `Уютный уголок`: в HUD показано название уровня, а каталог содержит его сокращённый набор из 10 предметов. Это подтверждает, что `lastSession.levelId` действительно восстановлен из local profile, а не только обновлён в DOM текущей страницы. Консоль после перезагрузки пуста.
