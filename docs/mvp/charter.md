# Decorium MVP Charter

## Status
Draft

## Owner
Qwen Studio Engineering Team

## Purpose
Определить цель, границы и критерии успеха MVP для игры Decorium - расслабляющего 3D-таймкиллера с элементами дизайн-симулятора.

## Scope
MVP фокусируется на проверке ключевой гипотезы: игрок размещает предметы в комнате, система оценивает стиль и эргономику, игрок получает понятную обратную связь.

### Входит в MVP
- Одна комната (level-001)
- Один стиль (Scandinavian)
- 5-10 предметов в каталоге
- 3-5 стилевых ограничений
- Базовые операции с предметами:
  - Размещение предмета в комнате
  - Перемещение предмета
  - Поворот предмета
  - Удаление предмета
  - Подтверждение расстановки
- Расчёт вектора комнаты на основе размещённых предметов
- Проверка стилевых ограничений
- Расчёт стиля score (плавная оценка, не бинарная)
- Расчёт star rating (1-5 звёзд)
- Список нарушений с конкретными сообщениями
- Минимальная обратная связь для игрока
- Загрузка данных из JSON
- Детерминированные тесты

### Не входит в MVP
- Экономика и магазин предметов
- Система прогрессии и уровней
- Несколько клиентов или профилей
- Процедурная генерация уровней
- Полноценная оценка эргономики (только стиль)
- Аудио и музыка
- Анимации и полировка UI/UX
- Облачные сохранения
- LLM-персонализация
- Платёжные системы
- Мультиплатформенная поддержка (только ПК для MVP)

## Key Hypothesis
Игрок получает удовольствие от процесса размещения предметов и понимает обратную связь о стиле интерьера.

## Success Metrics
- Игрок может завершить сессию за 2-5 минут
- Игрок понимает, почему получил такую оценку
- Игрок хочет попробовать ещё раз для улучшения результата
- Все тесты проходят детерминированно
- Оценка меняется плавно при изменении расстановки

## Risks
- Недостаточная ясность обратной связи
- Слишком сложная или слишком простая оценка
- Технические проблемы с производительностью
- Несоответствие ожиданий игроков
