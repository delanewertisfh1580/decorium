# Decorium MVP Out of Scope

## Status
Draft

## Owner
Qwen Studio Engineering Team

## Purpose
Чётко определить, что НЕ входит в MVP для предотвращения scope creep.

## Explicitly Out of Scope

### 1. Economy System
**Не реализуется:**
- Виртуальная валюта (монеты, кристаллы, золото)
- Цены на предметы
- Покупка предметов за реальные или виртуальные деньги
- Инвентарь игрока с ограниченным количеством предметов
- Торговля между игроками
- Ежедневные награды
- Боевые пропуска

**Причина:** Усложняет MVP, не проверяет ключевую гипотезу о геймплее.

### 2. Progression System
**Не реализуется:**
- Опыт игрока (XP)
- Уровни игрока
- Достижения и трофеи
- Разблокировка новых комнат
- Разблокировка новых стилей
- Разблокировка новых предметов
- Рейтинг игроков (leaderboards)
- Сезонные события

**Причина:** Мета-игра вторична по отношению к основному циклу размещения предметов.

### 3. Multiple Rooms & Levels
**Не реализуется:**
- Более одной комнаты
- Разные размеры комнат
- Разная геометрия комнат
- Процедурная генерация комнат
- Редактор комнат
- Сохранение пользовательских комнат

**Причина:** Одна комната достаточна для проверки гипотезы.

### 4. Multiple Styles
**Не реализуется:**
- Более одного стиля (только Scandinavian)
- Смешивание стилей
- Пользовательские стили
- LLM-генерация стилей

**Причина:** Один стиль достаточен для проверки механики оценки.

### 5. Ergonomics Scoring
**Не реализуется:**
- Правила эргономики (проходы, расстояния)
- Функциональная оценка расстановки
- Проверка доступности предметов
- Симуляция движения по комнате

**Причина:** Только стиль в MVP, эргономика добавляется позже.

### 6. Advanced UI/UX
**Не реализуется:**
- Анимации переходов между экранами
- Анимации появления предметов
- Частицы и визуальные эффекты
- Динамическое освещение
- Тени в реальном времени
- Пост-обработка
- Адаптивный UI для разных разрешений
- Настройки управления
- Настройки графики
- Экран загрузки с прогрессом

**Причина:** Минимальный UI достаточен для тестирования.

### 7. Audio
**Не реализуется:**
- Фоновая музыка
- Звуковые эффекты взаимодействия
- Звуки подтверждения
- Голосовая озвучка
- Настройки громкости
- Микширование аудио

**Причина:** Аудио не влияет на проверку основной механики.

### 8. Persistence
**Не реализуется:**
- Сохранение состояния комнаты
- Загрузка предыдущих сессий
- История попыток
- Профиль игрока
- Синхронизация между устройствами
- Облачные сохранения

**Причина:** Сессионный геймплей без сохранения достаточен для MVP.

### 9. Multiplayer & Social
**Не реализуется:**
- Мультиплеер
- Совместное размещение предметов
- Публикация комнат
- Голосование за комнаты
- Комментарии
- Делиться результатами
- Интеграция с социальными сетями

**Причина:** Одиночный опыт является приоритетом.

### 10. External Services
**Не реализуется:**
- Аналитика (Google Analytics, Unity Analytics)
- Краш-репорты (Sentry, Crashlytics)
- A/B тестирование
- Remote config
- LLM API для персонализации
- Платёжные шлюзы
- Авторизация через социальные сети

**Причина:** MVP должен работать автономно.

### 11. Platform Support
**Не реализуется:**
- iOS
- Android
- Консоли
- VR/AR
- Оптимизация под мобильные устройства
- Touch controls

**Причина:** Только ПК для MVP.

### 12. Content Expansion
**Не реализуется:**
- Более 10 предметов
- DLC packs
- Сезонный контент
- Лицензированные предметы
- Пользовательский контент (UGC)

**Причина:** Минимальный каталог достаточен.

### 13. Accessibility
**Не реализуется:**
- Поддержка скринридеров
- Цветовые режимы для дальтоников
- Субтитры
- Альтернативное управление
- Масштабирование UI

**Причина:** Добавляется после проверки основной гипотезы.

### 14. Localization
**Не реализуется:**
- Перевод на другие языки
- RTL поддержка
- Форматирование чисел/дат

**Причина:** Только один язык для MVP.

### 15. Marketing & Monetization
**Не реализуется:**
- Внутриигровые покупки
- Реклама
- Подписки
- Премиум контент
- Реферальные программы

**Причина:** MVP фокусируется на геймплее, не на монетизации.

## Boundary Cases

### Что делать если...

**...игрок просит сохранить комнату?**
→ Объяснить, что это планируется после MVP.

**...игрок хочет другой стиль?**
→ Зафиксировать фидбек, стиль добавляется в post-MVP.

**...нужно больше предметов?**
→ 5-10 предметов достаточно для проверки гипотезы.

**...тестеры просят мультиплеер?**
→ Это отдельный большой функционал, не в MVP.

## Post-MVP Candidates

Функции, которые могут быть добавлены после успешного MVP:

1. **Economy** - магазин предметов, валюта
2. **Progression** - уровни, достижения, разблокировки
3. **Multiple Rooms** - разные комнаты, генерация
4. **Multiple Styles** - Modern, Classic, Industrial, etc.
5. **Ergonomics** - правила расстановки, проверка проходов
6. **Audio** - музыка, звуки
7. **Persistence** - сохранения, профиль
8. **Mobile** - iOS/Android версия
9. **Social** - публикация, голосование
10. **LLM Personalization** - адаптивная обратная связь
