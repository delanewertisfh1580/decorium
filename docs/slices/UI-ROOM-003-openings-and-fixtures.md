# UI-ROOM-003 — Openings and Interior Fixtures

## Status
COMPLETED

## Requirement

Исправить архитектурные дефекты сцены: окно не должно быть непрозрачным декоративным блоком, в комнате должна быть читаемая дверь, а ambient-детали не должны быть случайно спрятаны в стенах или друг в друге.

## Acceptance criteria

- [x] Задняя стена разделена на сегменты вокруг оконного проёма.
- [x] Стекло окна прозрачное, с низкой opacity и без записи depth buffer.
- [x] Через окно читается внешний фасад/улица при прозрачности стены камеры.
- [x] На левой стене добавлена дверь с полотном, рамой и ручкой.
- [x] Бытовые ambient-детали остаются разнесёнными по сцене.
- [x] Свободное overlap/stacking-размещение пользовательских предметов не изменялось.

## Implementation

`RoomArchitecture.js` хранит детерминированные параметры проёмов. `RoomView` использует их для построения сегментов задней стены, прозрачного стекла, оконной рамы и боковой двери. Это presentation-only геометрия; RoomState и placement validation не затрагиваются.

## Manual QA checklist

1. Открыть сцену изнутри и найти дверь на левой стене.
2. Повернуть камеру к задней стене и убедиться, что окно пропускает внешний свет и окружение.
3. Выйти камерой за заднюю стену и проверить совместную работу стекла и `WallVisibility`.
4. Добавить пользовательские предметы друг на друга — свободное творческое размещение должно остаться прежним.
