# UI-VIS-004 — Minimal Contextual HUD

## Status
COMPLETED

## Goal
Сохранить 3D-сцену главным содержимым игры и показывать интерфейс только в момент, когда он нужен игроку.

## Implemented contract

- Каталог предметов по умолчанию свернут в компактный trigger; карточки открываются горизонтальным списком только по запросу.
- Прогресс оценки и звезды не занимают постоянную панель: они находятся внутри сводки в правом верхнем углу.
- Поворот, удаление и undo не находятся в постоянном нижнем dock. Они доступны в спойлере «Действия предмета» внутри сводки и скрыты, пока соответствующее действие невозможно.
- «Новая попытка» и справка находятся под компактной кнопкой дополнительных действий.
- Справка по клавишам и мыши свернута по умолчанию и открывается отдельно.
- После загрузки нет постоянного instructional banner. Status toast появляется только как ответ на выбор, размещение, перемещение, отмену или ошибку.
- Цвета используют существующие спокойные `Decorium` tokens: warm paper, sage accent, muted text и brass highlight.

## Interaction rules

1. Открыть «Каталог» → выбрать предмет → каталог автоматически сворачивается, потому что действие размещения стало доступным.
2. Выбрать предмет в сцене → открыть «Сводка» → при необходимости использовать контекстные действия.
3. Открыть `•••` → посмотреть справку или начать новую попытку.
4. Нажать «Оценить» → получить score/stars/feedback в evaluation client UI.

## Out of scope

HUD не меняет правила свободного размещения, stacking, scoring или данные каталога. Accessibility touch target остаётся не меньше 44px, а desktop/mobile layout использует safe areas.

- `tests/Presentation/ToolbarView.test.js` проверяет отсутствие item actions в постоянном dock.
