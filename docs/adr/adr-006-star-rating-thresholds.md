# ADR-006: Star Rating Thresholds

## Status
Accepted

## Date
2024-01-01

## Owner
Qwen Studio Engineering Team

## Title
Использовать фиксированные пороги TotalScore для определения Star Rating

## Context
Игрок должен получать понятную обратную связь о качестве расстановки в виде звёзд (1-5).

Необходимо определить:
- Как маппить непрерывный score (0.0-1.0) на дискретные звёзды (1-5)
- Какие пороги обеспечивают хорошую дифференциацию
- Как избежать ситуации "всегда 5 звёзд" или "невозможно получить 5 звёзд"

Рассмотренные подходы:
1. Равные интервалы (0.2, 0.4, 0.6, 0.8) - слишком просто
2. Экспоненциальные пороги - сложно для понимания
3. Фиксированные пороги на основе тестовых данных - выбрано

## Decision
Использовать фиксированные пороги:

| Star Rating | TotalScore Threshold |
|-------------|---------------------|
| ⭐⭐⭐⭐⭐ (5) | >= 0.9 |
| ⭐⭐⭐⭐ (4)  | >= 0.7 |
| ⭐⭐⭐ (3)   | >= 0.5 |
| ⭐⭐ (2)    | >= 0.3 |
| ⭐ (1)     | < 0.3 |

### Формула

```typescript
export class StarRatingPolicy {
  determine(totalScore: number): number {
    if (totalScore >= 0.9) return 5;
    if (totalScore >= 0.7) return 4;
    if (totalScore >= 0.5) return 3;
    if (totalScore >= 0.3) return 2;
    return 1;
  }
}
```

### Обоснование порогов

- **0.9 для 5 звёзд**: Требует почти идеального соответствия стилю, даёт чувство достижения
- **0.7 для 4 звёзд**: Хороший результат, достижим при понимании правил
- **0.5 для 3 звёзд**: Средний результат, игрок понял основы но может лучше
- **0.3 для 2 звёзд**: Плохой результат, явные нарушения стиля
- **< 0.3 для 1 звезды**: Очень плохой результат, полное несоответствие

### Примеры сценариев

**Сценарий A: Идеальная расстановка**
- Все ограничения выполнены
- Penalties = [0.0, 0.0, 0.0]
- StyleScore = 1.0
- **Star Rating: 5** ⭐⭐⭐⭐⭐

**Сценарий B: Хорошая расстановка**
- Одно ограничение слегка нарушено
- Penalties = [0.0, 0.15, 0.0]
- StyleScore = 0.85
- **Star Rating: 4** ⭐⭐⭐⭐

**Сценарий C: Средняя расстановка**
- Несколько нарушений
- Penalties = [0.2, 0.3, 0.1]
- StyleScore = 0.6
- **Star Rating: 3** ⭐⭐⭐

**Сценарий D: Плохая расстановка**
- Серьёзные нарушения
- Penalties = [0.4, 0.5, 0.3]
- StyleScore = 0.4
- **Star Rating: 2** ⭐⭐

**Сценарий E: Очень плохая расстановка**
- Все ограничения нарушены
- Penalties = [0.6, 0.7, 0.5]
- StyleScore = 0.2
- **Star Rating: 1** ⭐

## Consequences

### Positive
- Понятная шкала оценки для игроков
- Чувство достижения при получении 5 звёзд
- Постепенная прогрессия (легко улучшить с 2 до 3, сложнее с 4 до 5)
- Легко тестировать детерминированно

### Negative
- Пороги могут потребовать калибровки после фидбека
- Могут быть пограничные случаи (0.89 vs 0.90)

### Neutral
- Требуется документировать пороги
- Нужно собирать фидбек для post-MVP adjustments

## Calibration Plan

После MVP собрать данные:
- Распределение оценок игроков
- Время получения каждой оценки
- Фидбек о справедливости оценки

Если > 80% игроков получают 5 звёзд → увеличить пороги  
Если > 80% игроков получают 1-2 звезды → уменьшить пороги
